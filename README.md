# readslug

Read CSV/TSV slug tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/readslug/

## Install / run

```bash
git clone https://github.com/theworker02/readslug.git
cd readslug
node src/cli.js
node --test
```
